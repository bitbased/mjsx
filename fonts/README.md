# fonts/

Drop any `.ttf` / `.ttc` / `.otf` monospace font in here and the sim's FACE
button (host-font text mode, `TXT:TTF`) picks it up automatically, listed
before the system faces.

Shipped:

- `RobotoMono-Bold.ttf` — Roboto Mono, © The Roboto Mono Project Authors,
  licensed under the Apache License 2.0
  (https://github.com/googlefonts/robotomono). Redistribution permitted
  with this notice.

System faces discovered automatically (not redistributed): SF Mono,
PT Mono, Menlo on macOS; DejaVu Sans Mono on Linux; Consolas on Windows.
