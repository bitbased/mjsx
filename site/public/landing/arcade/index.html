THREE PROGRAMS

RUNNING HERE, ON THE SAME ENGINE THAT RUNS ON THE GLASS

mjsx is a JSX user-interface engine for the small displays on microcontrollers. You write components; it lays them out, hit-tests them, and paints them through ten drawing calls and a clock.

It is one file of ES5 — the same core on a 240×240 round panel, a 480×320 screen, an ESP32, a Pi, or this page. The cabinets below are the shipped examples running on it right now.

  • one ES5 file, no VDOM
  • width-in, height-out layout
  • round glass as geometry, not a special case
  • touch, physical keys and virtual keyboards
01ASTEROIDS examples/asteroids · real‑time

CLICK THE SCREEN, THEN ARROWS + SPACE

◀ ▶ turn ▲ thrust SPACE fire HOLD + DRAG steer
fixed 16 ms timestep, so it plays the same at 15 Hz and 120 Hz the world is a torus — and on round glass it wraps at the rim ship-centred mode scrolls the field, not the ship seeded field: the same run every time, on every panel
02INPUT examples/input · every way in at once

TAP A FIELD, THEN TYPE — YOUR KEYBOARD OR THE ONE ON THE GLASS

TAP place caret DRAG scroll text HOLD + DRAG walk caret TAB next field
QWERTY, T9, number pad and a one-row STRIP — chosen to fit the glass on the circle each row is inset to its own chord, so no key is under the bezel a custom keyboard is ordinary JSX calling UI.type() physical keys, touch and virtual keys all arrive the same way
03DRAW examples/canvas · pixels you keep

DRAG TO DRAW

DRAG stroke SWATCH colour DIRECT straight to the bitmap CLR clear
the live stroke is drawn as ordinary ops, over the bitmap on release it is rasterised into a canvas source and leaves the op stream the frame then composites it with a single blit on round glass the canvas is the whole circle, controls ride the rim
04SOURCE edit it · it rebuilds as you type
the real transpiler and the real engine, not a preview the call list is what the frame actually emitted switch the panel and the same source meets different glass load any example into the slot and edit it live
