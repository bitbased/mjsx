JSX user-interface engine for microcontroller glass — three typical applications, running

Description

mjsx renders a JSX component tree to a display through ten drawing calls and a clock. The three figures below are the shipped examples, running in this page on the same core file that runs on the hardware. They are not illustrations — touch them.

Section 4 exposes the whole path: type source in and watch it transpile, mount and paint on whichever panel you choose.

Features

  • ES5 core, one file
  • Width-in, height-out layout, single pass
  • Round glass handled as geometry, not a special case
  • Full input stack: physical, touch, virtual keyboards
  • Canvas sources compositing with one blit
  • Any panel from 172×320 to 480×320

Typical application — real-time game

Figure 1. 240 × 240 round
Table 1 — asteroids, examples/asteroids/app.jsx
ParameterBehaviour
TimestepFixed 16 ms, read from sys.millis(); at most four steps caught up per frame. Play is identical at 15 Hz and 120 Hz.
TopologyTorus. One wrap rule serves every panel; on round glass it wraps at the rim.
SpawningA rock is born only at an edge, clear of the ship.
CameraShip-centred mode holds the ship fixed and scrolls the field; 1 px stars carry the parallax.
RocksClosed polylines, not filled discs.

CONTROLS — click the panel, then arrow keys and space; or press and drag to steer toward the pointer.

2.0

Typical application — text entry

Figure 2. 240 × 280
Table 2 — input, examples/input/app.jsx
ParameterBehaviour
PhysicalPrintable keys insert; Backspace and arrows edit; Tab walks the fields and scrolls them into view.
TouchTap places the caret, drag scrolls overflowing text, press-and-hold then drag walks the caret under the finger.
LayoutsQWERTY where ten columns fit, T9 where four do, a number pad, and a single scrolling STRIP below that.
RoundEach row inset to its own chord; the bottom row is narrowest, and no key falls under the bezel.
CustomThe PIN pad is ordinary JSX whose taps call UI.type().

CONTROLS — tap a field, then type on your own keyboard or the one on the glass.

Typical application — freehand raster

Figure 3. 240 × 280
Table 3 — canvas, examples/canvas/app.jsx
ParameterBehaviour
Live strokeOrdinary drawing calls painted over the bitmap while the finger is down, so it previews at full speed.
CommitOn release the stroke rasterises into a canvas source and leaves the op stream entirely.
Frame costOne composite. A hundred strokes emit the same call list as none.
Direct modeSkips the preview; each segment goes straight into the bitmap.
