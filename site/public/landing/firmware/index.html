Each block below is a program from the repository, live on its target panel.

mjsx is a JSX user-interface engine for the small displays on microcontrollers. You write components; it lays them out, hit-tests them and paints them through ten drawing calls and a clock.

One file of ES5 — the same core on a 240×240 round panel, a 480×320 screen, an ESP32, a Pi, or this page. The manifest below lists the shipped examples; each one is already running on its panel.

  • one ES5 file, no VDOM
  • width-in, height-out layout
  • round glass as geometry
  • touch, keys and virtual keyboards

0x00000ASTEROIDS examples/asteroids/app.jsx
target 240 × 240 round
  • Fixed timestep. 16 ms steps read from sys.millis(), at most four caught up per frame — identical play at 15 Hz and 120 Hz.
  • Torus world. One wrap rule for every panel; on the circle it wraps at the rim.
  • Fair spawning. A rock is born only at an edge, clear of the ship.
  • Ship-centred mode. The field scrolls past a fixed ship; 1 px stars carry the parallax.

0x04000INPUT examples/input/app.jsx
target 240 × 280
  • Physical keys. Printable keys insert, Backspace and arrows edit, Tab walks the fields and scrolls them into view.
  • Touch. Tap places the caret, drag scrolls overflowing text, hold-and-drag walks the caret under the finger.
  • Four layouts. QWERTY, T9, number pad and a scrolling STRIP, chosen to fit the glass.
  • Round. Each row inset to its own chord — the bottom row is narrowest and no key hides under the bezel.
  • Custom pads. The PIN keyboard is ordinary JSX calling UI.type().

0x08000CANVAS examples/canvas/app.jsx
target 240 × 280
  • Live stroke. Ordinary drawing calls over the bitmap while the finger is down, so it previews at full speed.
  • Commit on release. The stroke rasterises into a canvas source and leaves the op stream — pixels now, not a path.
  • One composite per frame. A hundred strokes emit the same call list as none.
  • Direct mode. Skips the preview; each segment goes straight into the bitmap.
