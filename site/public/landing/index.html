Five landing pages for one engine.

mjsx is JSX for microcontrollers, a Raspberry Pi, the desktop and the browser: one portable core file that lays out, draws and handles touch, reaching pixels through exactly ten gfx calls plus a clock. Anything that realizes those ten is a backend — a chip, a terminal, a native window, a browser tab.

Below are five complete alternative designs for that same page. They are not chapters and not a sequence: each one is a finished attempt at the whole story, and they carry the same checkable facts in five different voices.

These are alternatives, not a set. Pick one. Every page below describes the same repository, states the same numbers, and links nowhere off itself — none of them, and not this one, makes a single network request.

About the subject

mjsx is one file of ES5 / MicroQuickJS‑safe JavaScript — 2,526 lines holding h(), the layout pass, hit‑testing and the touch state machine — that reaches pixels through ten gfx calls plus sys.millis. No virtual DOM and no reconciler: a dirty frame simply redraws. Six backends exist and run today (a headless rasterizer, an ANSI terminal, an SDL window, a browser mirror, WASM running the same MicroQuickJS bytecode a chip runs, and the ESP32 itself), and it drives a four‑board fleet daily, one of which is round.

hobby project MIT licensed zero dependencies not published to npm not on a public git host

It is a hobby project, open‑sourced as‑is and still pre‑publication: the "private": true in its package.json is deliberate, so there is no install line here and no repository link to hand you. If you have a copy, pin to your checkout.

These five pages are alternative designs for the same project, not five different products. This chooser and all five of them are single self‑contained files: no fonts fetched, no scripts fetched, no images fetched, no analytics — nothing here makes a network request.
