THREE PROGRAMS, LIVE

Running on the engine that runs on the glass · click a panel to give it your keyboard

mjsx is a JSX user-interface engine for the small displays on microcontrollers. You write components; it lays them out, hit-tests them and paints them through ten drawing calls and a clock.

One file of ES5 — the same core on a 240×240 round panel, a 480×320 screen, an ESP32, a Pi, or this page. Every module below is a shipped example running on it.

  • one ES5 file, no VDOM
  • width-in, height-out layout
  • round glass as geometry
  • touch, keys and virtual keyboards
01ASTEROIDS examples/asteroids/app.jsx

02INPUT examples/input/app.jsx
240 × 280
physical
type on your own keyboard: printable keys insert, Backspace and arrows edit, Tab walks the fields and scrolls them into view
touch

QWERTY where ten columns fit, T9 where four do, a number pad, and a single scrolling STRIP below that
round
each row inset to its own chord, so the bottom row is narrowest and no key sits under the bezel
custom

03DRAWING examples/canvas/app.jsx
240 × 280
live
while the finger is down the stroke is ordinary ops, painted over the bitmap, so it previews at full speed
commit
on release it is rasterised into a canvas source and leaves the op stream — it is pixels now, not a path
cost
the frame composites one image, so a hundred strokes emit the same call list as none
direct
skips the preview and rasterises each segment straight into the bitmap
round
the canvas takes the whole disc; the controls ride the rim on an arc
