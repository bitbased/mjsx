00The signal source → glass, with every probe point exposed

The three specimens below are all made of this. Edit the source and the rest of the chain follows: the transpiler, the call list, the pixels.

mjsx is a JSX user-interface engine for the small displays on microcontrollers. You write components; it lays them out, hit-tests them and paints them through ten drawing calls and a clock.

It is one file of ES5 — the same core on a 240×240 round panel, a 480×320 screen, an ESP32, a Pi, or this page. Each specimen below is a shipped example running on it.

  • one ES5 file, no VDOM
  • width-in, height-out layout
  • round glass as geometry, not a special case
  • touch, physical keys and virtual keyboards
01Asteroids examples/asteroids/app.jsx
240 × 240 · round
  1. A fixed timestep, from a clock the chip has. The loop reads sys.millis() and advances the world in 16 ms steps, catching up at most four at a time. The same file plays identically on a 15 Hz panel and a 120 Hz browser.
  2. The world is a torus. One wrap rule covers every shape; on the circle it wraps at the rim, and a rock is only ever born at an edge, never in your lap.
  3. Ship-centred mode scrolls the field. The ship holds the middle and the rocks and 1 px stars carry the offset — the parallax you see is the world moving past a fixed camera.
  4. Rocks are outlines, not discs. Each is a closed polyline, which is what an asteroid looks like and what the vector hardware this genre came from could actually draw.

TRY → click the glass, then hold the mouse down and drag around the circle: the ship turns to face your finger.

02Input examples/input/app.jsx
240 × 280
  1. Your keyboard works. Click a field and type: printable keys insert, Backspace and the arrows edit, Tab walks the fields and scrolls them into view.
  2. The virtual keyboard picks itself. QWERTY where ten columns fit, T9 where four do, and a single scrolling STRIP below that — switch panels and watch the layout change with the glass.
  3. On the circle, every row is inset to its own chord. A round keyboard is a trapezoid: the bottom row sits nearest the rim and is narrowest, which is the difference between a usable space bar and one half under the bezel.
  4. A custom keyboard is just JSX. The PIN field raises a pad written as ordinary components whose taps call UI.type() — the same path a physical key takes.

TRY → switch to 240×240 round and open the keyboard. Then compare it against the same source on 320×172.

03Drawing examples/canvas/app.jsx
240 × 280
  1. The live stroke is ordinary drawing. While your finger is down the path is emitted as normal ops, painted over the bitmap, so it previews at full speed.
  2. On release it is committed. The stroke is rasterised into a canvas source and disappears from the op stream entirely — it is pixels now, not a path.
  3. The frame then composites one image. A drawing with a hundred strokes emits the same call list as an empty one.
  4. Round glass gets the whole circle. The canvas takes the full disc and the controls ride the rim on an arc, rather than spending a strip of drawing surface on a square toolbar.

TRY → scribble, then hit DIRECT and scribble again: that mode skips the preview and rasterises each segment straight into the bitmap.
