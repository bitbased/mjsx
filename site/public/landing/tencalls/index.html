Porting it means writing ten functions.

Not ten files, not ten classes — ten functions and a clock. To prove it rather than assert it, this page implements them itself, in plain Canvas2D, and hands that to the engine as its only backend. The panels below are a real example from the repository running on the code in the box beside them.

THE ENTIRE BACKEND written in this page · Canvas2D

    

    

      

      

        Look at the typeface. This backend draws text with the browser's own
        font instead of the project's bitmap faces — because choosing a font is a
        backend's job, not the engine's. The engine only ever asks “draw this
        string, at this size, in this colour, here”. That is exactly the seam a
        port lives on, and you are looking straight at it.
      

    

  


  

    
the contract, in full

    
There is no second page.

    

      
CallWhat a backend must do

      
        
gfx.clear(color)Fill the surface. Start of every frame.

        
gfx.rect(x,y,w,h,color,radius)1px outline, optionally rounded.

        
gfx.frect(x,y,w,h,color,radius)Filled rect. The workhorse.

        
gfx.circle(cx,cy,r,color,filled)Centre, radius, filled or not.

        
gfx.line(x0,y0,x1,y1,color)1px line. Thickness is the core's problem.

        
gfx.text(x,y,size,color,str)Draw a string. The font is yours to pick.

        
gfx.clip(x,y,w,h)Set the clip rect — one, not a stack.

        
gfx.unclip()Remove it.

        
gfx.width() / gfx.height()Logical surface size in pixels.

        
sys.millis()Milliseconds since boot. Any epoch, must advance.

      
    

    

      poly and blit exist and are optional — the core

      is why this page can ignore them entirely and everything still draws.
    

  


  

    
what that buys

    
Six backends, one core, no abstraction layer.

    

      Because the surface is this narrow, a backend is a file rather than a
      subsystem, and the engine needs no renderer interface, no driver model and no
      capability negotiation. The ones in the repository today:
    

    

      
BackendDraws into

      
        
pure-jsIts own scanline rasterizer — the reference, and what every documentation figure is drawn with.

        
terminalHalf-block cells and ANSI colour.

        
sdlA native desktop window.

        
httpA browser, over a websocket, by streaming the op list.

        
wasmThe same MicroQuickJS bytecode a chip runs, compiled to WebAssembly.

        
esp32C functions bound into the firmware's stdlib table.
